### امکانات پنل مدیریت

| بخش | توضیح |
|---|---|
| 📊 داشبورد | ۸ کارت آماری + نوبت‌ها به تفکیک وضعیت + آخرین رویدادها |
| 🌿 مدیریت خدمات | افزودن / ویرایش / حذف / فعال و غیرفعال‌سازی خدمات با تعرفه و آیکون |
| 👩‍⚕️ مدیریت مشاوران | پروفایل کامل مشاوران با تصویر، تخصص، امتیاز و ترتیب نمایش |
| 🎓 مدیریت دوره‌ها | دوره‌های آموزشی با اتصال به مشاور به‌عنوان مدرس |
| 📰 مدیریت مقالات | ویرایشگر مقاله با پیش‌نویس/انتشار، دسته‌بندی و زمان مطالعه |
| 📅 مدیریت نوبت‌ها | فیلتر بر اساس وضعیت، تغییر وضعیت (در انتظار/تأیید/انجام/لغو)، خروجی CSV |
| ✉️ مدیریت پیام‌ها | مشاهده، علامت‌گذاری خوانده‌شده، پاسخ ایمیلی مستقیم، حذف |
| 🗂 مدیریت شکایات | تغییر وضعیت + ثبت پاسخی که کاربر در صفحه پیگیری می‌بیند |
| 📮 مدیریت خبرنامه | فهرست اعضا + خروجی CSV |
| ⚙️ تنظیمات | اطلاعات تماس، متن درباره ما، شبکه‌های اجتماعی + تغییر رمز عبور مدیر |

### ویژگی‌های فنی

- ⚙️ **بکاند:** Python 3 + Flask 3 + SQLAlchemy (بدون وابستگی سنگین)
- 💾 **دیتابیس:** SQLite تک‌فایلی (`amghazi.db`) — بدون نیاز به نصب سرور دیتابیس
- 🇮🇷 **تاریخ شمسی:** نمایش خودکار تاریخ‌ها به شمسی با کتابخانه `jdatetime` + اعداد فارسی
- 🔐 **امنیت:** رمز عبور هش‌شده (Werkzeug)، نشست ورود، CSRF-safe با Post/Redirect، تأیید حذف‌ها
- 📱 **واکنش‌گرا:** طراحی موبایل‌فرست برای تمام صفحات
- 🚀 **بدون بیلد:** بدون Node، بدون npm — همه‌چیز با پایتون اجرا می‌شود

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.10 یا بالاتر
- pip

### مراحل نصب

```bash
# ۱) دریافت پروژه
git clone https://github.com/samaneh-IT-rose/amghazi.git
cd amghazi

# ۲) ساخت محیط مجازی (اختیاری اما پیشنهاد می‌شود)
python -m venv venv

# فعال‌سازی در ویندوز:
venv\Scripts\activate
# فعال‌سازی در لینوکس/مک:
source venv/bin/activate

# ۳) نصب وابستگی‌ها
pip install -r requirements.txt

# ۴) ساخت دیتابیس و داده اولیه
python init_db.py

# ۵) اجرای سرور
python run.py
```

سپس در مرورگر:

| آدرس | توضیح |
|---|---|
| `http://127.0.0.1:5000` | سایت عمومی |
| `http://127.0.0.1:5000/admin/login` | ورود به پنل مدیریت |

### اطلاعات ورود پیش‌فرض

- **نام کاربری:** `admin`
- **رمز عبور:** `admin123`

> ⚠️ **مهم:** بلافاصله پس از اولین ورود، از بخش «تنظیمات ← حساب مدیر» رمز عبور را تغییر دهید.

### تغییر اطلاعات ورود قبل از اولین اجرا (اختیاری)

می‌توانید با متغیرهای محیطی، حساب مدیر را متفاوت بسازید:

```bash
export ADMIN_USERNAME=myadmin
export ADMIN_PASSWORD=mypassword123
export SECRET_KEY=a-very-random-string
python init_db.py
```

## 🛠 راهنمای پنل مدیریت

### گردش کار روزانه

1. **مشاهده نوبت‌های جدید:** داشبورد ← کارت «در انتظار بررسی» یا منوی «نوبت‌ها»
2. **تأیید نوبت:** در جدول نوبت‌ها، از منوی کشویی وضعیت را به «تأیید شده» تغییر دهید؛ با تغییر خودکار ذخیره می‌شود.
3. **تماس با کاربر:** شماره تلفن کاربر در جدول نوبت‌ها نمایش داده می‌شود.
4. **پاسخ به پیام‌ها:** منوی «پیام‌ها» ← دکمه «پاسخ با ایمیل» (باز شدن میل‌کلاینت) یا تماس با شماره ثبت‌شده.
5. **رسیدگی به شکایات:** منوی «شکایات» ← تغییر وضعیت + نوشتن «یادداشت» (این متن توسط کاربر در صفحه پیگیری شکایت با کد `CM-xxxxxx` قابل مشاهده است).
6. **انتشار محتوا:** هر بخش (خدمت/مقاله/دوره/مشاور) دارای دکمه «+ افزودن» است؛ با برداشتن تیک «فعال باشد» آیتم از سایت پنهان ولی در پنل باقی می‌ماند.

### نکات محتوایی

- **آیکون‌ها:** در خدمات، مقالات و دوره‌ها می‌توانید هر ایموجی بگذارید (🌿 💍 🎓 📰 ⭐ ...).
- **تصویر مشاوران:** در فیلد «آدرس تصویر» یک لینک تصویر قرار دهید؛ اگر خالی بماند آواتار متنی با حروف اول نام ساخته می‌شود.
- **تعرفه:** اگر قیمت را صفر بگذارید، به‌جای قیمت عبارت «تماس بگیرید» نمایش داده می‌شود.
- **تاریخ شمسی:** تاریخ‌ها را با فرمت `۱۴۰۴/۰۸/۱۵` در فیلدهای متنی وارد کنید.
- **HTML ساده مجاز است:** در شرح خدمات و متن مقالات می‌توانید از تگ‌های `p` ،`h2` ،`h3` ،`ul` ،`li` ،`b` استفاده کنید؛ اگر متن را بدون تگ بنویسید، خط‌شکستگی‌ها به‌صورت خودکار نمایش داده می‌شوند.
- **خروجی CSV:** نوبت‌ها و اعضای خبرنامه دکمه «دانلود CSV» دارند؛ فایل با انکودینگ UTF-8 BOM ذخیره می‌شود و مستقیم در اکسل فارسی باز می‌شود.

## 💾 دیتابیس

SQLite و ۱۰ جدول:

| جدول | کاربرد | فیلدهای کلیدی |
|---|---|---|
| `admins` | حساب مدیران | username، password_hash |
| `services` | خدمات مشاوره | title، slug، icon، price، duration_minutes، is_active، sort_order |
| `psychologists` | مشاوران | name، title، specialty، degree، bio، rating، experience_years |
| `courses` | دوره‌ها | title، teacher_id، price، sessions_count، start_date، format |
| `articles` | مقالات | title، slug، category، content، views، is_published |
| `appointments` | نوبت‌ها | full_name، phone، service_id، psychologist_id، status |
| `contact_messages` | پیام‌های تماس | name، email، phone، message، is_read |
| `complaints` | شکایات | name، phone، message، status، admin_note |
| `newsletter_subscribers` | خبرنامه | email (یکتا) |
| `settings` | تنظیمات سایت | key / value |

### پشتیبان‌گیری

کل دیتابیس یک فایل است (`amghazi.db`). کافی است آن را کپی کنید:

```bash
cp amghazi.db backup-$(date +%F).db
```

### ریست کامل

```bash
rm amghazi.db
python init_db.py
```

> توجه: فایل دیتابیس در `.gitignore` قرار دارد و در گیت آپلود نمی‌شود؛ پس از هر clone باید `python init_db.py` اجرا شود.

## 🎨 شخصی‌سازی ظاهر

فایل `app/static/css/style.css` با متغیرهای CSS شروع می‌شود؛ برای تغییر رنگ‌بندی فقط این متغیرها را عوض کنید:

```css
:root {
  --primary: #0e7c7b;        /* رنگ اصلی (تیل) */
  --primary-dark: #0a5c5b;   /* تیره‌تر — نوارها و فوتر */
  --primary-deep: #074443;   /* عمیق‌ترین — هیرو و سایدبار پنل */
  --accent: #e8a33d;         /* رنگ تأکیدی — دکمه‌های CTA */
  --bg: #f7fbfa;             /* پس‌زمینه صفحات */
  --font: "Vazirmatn", Tahoma, sans-serif;  /* فونت */
}
```

- فونت وزیرمتن از CDN بارگذاری می‌شود؛ برای استفاده آفلاین، فایل فونت را در `static/` قرار داده و لینک `base.html` را تغییر دهید.
- لوگو: در `base.html` و `base_admin.html` ایموجی 🌿 در کلاس `brand-logo` را عوض کنید یا به `<img>` تبدیل کنید.

## 🌐 استقرار (Deployment)

### اجرای تولیدی با Gunicorn (لینوکس)

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:8000 "app:create_app()"
```

> نکته: `run.py` برای توسعه با دیباگ است؛ در سرور از gunicorn استفاده کنید. اولین بار `python init_db.py` را اجرا کنید.

### Nginx (پیشنهادی به‌عنوان Reverse Proxy)

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /static/ {
        alias /path/to/amghazi/app/static/;
        expires 30d;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### چک‌لیست امنیتی پیش از انتشار

- [ ] `SECRET_KEY` را با متغیر محیطی به مقدار تصادفی تغییر دهید
- [ ] رمز مدیر پیش‌فرض را عوض کنید
- [ ] دیباگ را خاموش نگه دارید (`run.py` فقط برای توسعه)
- [ ] به‌صورت دوره‌ای از `amghazi.db` بکاپ بگیرید

## ❓ پرسش‌های متداول

**۱) بعد از اجرا صفحه سفید یا خطای دیتابیس می‌بینم.**
ابتدا `python init_db.py` را اجرا کرده‌اید؟ این دستور باید حداقل یک بار اجرا شود.

**۲) رمز مدیر را فراموش کردم.**
دیتابیس را حذف و دوباره بسازید (`rm amghazi.db && python init_db.py`) — توجه کنید همه داده‌ها از بین می‌رود، یا در محیط پایتون:

```python
from app import create_app
from app.models import Admin, db
app = create_app()
with app.app_context():
    a = Admin.query.filter_by(username="admin").first()
    a.set_password("newpass123")
    db.session.commit()
```

**۳) داده‌های نمونه را چطور حذف کنم؟**
از خود پنل مدیریت هر آیتم را حذف کنید، یا جدول مربوطه را خالی کنید و مقاله‌های واقعی خودتان را بنویسید.

**۴) آیا پرداخت آنلاین دارد؟**
این نسخه بر رزرو و تأیید تلفنی متمرکز است. برای اتصال درگاه پرداخت می‌توانید پس از تأیید نوبت، لینک پرداخت را برای کاربر ارسال کنید یا ماژول درگاه به فرم رزرو اضافه کنید.

**۵) چطور نسخه‌های جدید را آپدیت کنم؟**
```bash
git pull
pip install -r requirements.txt
python init_db.py   # بدون حذف دیتابیس، فقط جداول جدید را می‌سازد
```
